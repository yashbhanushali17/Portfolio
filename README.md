# Yash Nanda – Portfolio

A modern, responsive personal portfolio showcasing my projects, skills, and experience in Machine Learning, Python Backend Development, and Web Development.

The project was built using HTML, CSS, JavaScript, and FastAPI with the help of AI-assisted development (vibe coding). I focused on designing, customizing, integrating features, optimizing performance, and bringing everything together into a polished, production-ready portfolio.

🌐 **Live Demo:** https://yashnanda-portfolio.vercel.app/

---

## Features

- Responsive portfolio design
- Dark & Light theme
- Interactive animations and smooth scrolling
- Custom canvas background
- Project filtering and search
- Animated skills and statistics
- Resume preview and download
- AI-powered portfolio chatbot
- Contact form with FastAPI & Resend integration
- Hidden **GOAT Mode** with a Messi-inspired themed experience

## Getting Started

```bash
git clone https://github.com/yashbhanushali17/Portfolio.git
cd Portfolio
```

Run the frontend using any static server or open `index.html`.

For the backend:

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

Create a `.env` file with your required API keys before running the backend.
